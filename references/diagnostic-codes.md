# 특허·실용신안 심사품질 진단코드

출처: 사용자 제공 「심사품질 진단기준」(2026. 9. 개정), Ⅰ. 특허·실용신안 심사품질 진단 항목. 아래 84개 코드는 원문의 진단유형 첫 문장을 따른다. 원문의 ①·② 등은 **예시이며 한정 열거가 아니다**. 원문 일러두기는 심사문서 작성 시기와 관계없이 적용하고, 특허·실용신안 항목은 2024. 4. 23. 이후 심사품질진단부터 적용한다고 명시한다. 이 파일은 특허·실용신안 전용이며 상표·디자인 코드를 포함하지 않는다. 원문에 없는 `11xx` 코드를 만들지 않는다.

OA/RD/RC 규칙 ID는 검사 절차를, 네 자리 진단코드는 확인된 진단유형을 가리킨다. 진단 결과에 **대상 문서·시점, 청구항, 조항, 근거 쪽수, 결정 경과 및 코드 선택 근거**를 붙인다. 코드별 문구의 `특허결정`, `거절결정`, `최종결정에 명백하게 영향`, `다른 정당한 거절이유` 같은 조건을 생략하지 않는다. 통지서만 확보했거나 후속 결정을 확인하지 못하면 거절결정 전제 코드를 확정하지 않는다. 동일 사안을 중복 집계하지 않도록 실체적 오류와 통지서의 기재 오류를 구별한다. 공식 문구와 예시를 더 확인해야 하면 제공받은 기준 원문을 대조한다.

## 결정 경과에 따른 코드 선택

- **잘못된 거절이유의 결론:** 해당 이유로 거절결정하고 다른 정당한 거절이유가 없으면 해당 분야의 `xx12`(기타 특허요건 `0717`, 보정 `0812` 등 별도 문구 참조)를 검토한다. 거절결정 전 통지에 그쳤거나 다른 정당한 거절이유가 있다면 해당 `xx21`을 검토한다. 단순히 틀린 이유가 있다는 사실만으로 `xx12`를 부여하지 않는다.
- **놓친 하자:** 특허결정에도 남은 중대한 하자(`xx11` 또는 그 분야의 특허결정 코드), 거절결정 시 미지적 사유(`xx31`), 등록결정의 경미한 사항(`xx32`), 통지하지 않았지만 심사 중 자연 해소된 사유(`xx33`/`xx34`)를 각 코드의 명시 조건에 맞춰 구별한다. 숫자 끝자리만으로 기계적으로 일반화하지 않는다.
- **기재의 품질:** 실체 판단 오류(`01`–`09`)와 의견제출통지서 문구·인용문헌·대비의 오류(`12`), 결정서(`13`), 기타통지서(`14`), 절차(`10`)는 각자의 요건을 따로 확인한다. `xx35`는 해당 분야의 '기타 바람직하지 않은 거절이유'에만 쓴다.
- **증거 부족:** 결정 경과, 당시 청구항, 명세서 또는 인용문헌을 확인하지 못하면 `조건부 점검`/`확인 불가`로 두고 확정 코드를 억지로 부여하지 않는다.

| `1422` | 보정각하결정서에 기재된 내용이 잘못되거나 불명확한 경우 |
| `1423` | 분할, 변경출원에 대한 불인정예고통지서에 기재된 내용이 잘못되거나 불명확한 경우 |
| `1435` | 기타 바람직하지 않은 거절이유를 통지한 경우 |

### 우수사례

| 코드 | 진단유형 (공식 기준) |
|---|---|
| `1511` | 아래 1521 내지 1522 요건을 모두 충족하는 경우로서, 심사내용이 우수하여 타 심사관의 모범이 되는 심사사례 |
| `1521` | 적절한 선행기술을 활용하고 아래 공통사항을 모두 충족하는 경우 |
| `1522` | 심사통지서가 논리적이고 간결하게 작성된 경우로서, 다음 (1) 내지 (4)의 내용을 만족하고 아래 공통사항을 모두 충족하는 경우 |

## 특히 혼동하기 쉬운 유형

### 제42조 기재요건의 오지적: `0412`/`0421`과 `0512`/`0521`

- **발명의 설명** 기재요건(제42조제3항 등)을 잘못 지적한 경우는 `04xx`, **청구범위** 기재요건(제42조제4항)은 `05xx`이다. 제42조 전체를 `0521`로 묶지 않는다. 시행령 제5조의 **청구범위 기재방법**은 `06xx`다.
- 청구범위 기재요건 위반이 아닌데 이를 이유로 **거절결정했고 다른 정당한 거절이유가 없다면** `0512`다. 잘못 통지했지만 그 이유로 거절결정하지 않았거나, 거절결정에 다른 정당한 거절이유가 있다면 `0521`이다(원문 `0521` ①·②). 발명의 설명은 동일한 경과를 원문 `0412`/`0421` 조건에 맞춰 검토한다.
- 과거 사례의 `경화물`(경화성 엘라스토머 조성물의 경화물임이 청구항과 관련 종속항에서 명확한 경우), `임의로`(선택적 포함이라는 뜻이 명확한 경우)에 대한 제42조제4항제2호 불명확성 지적은, **통지 단계의 오지적이라면 `0521`**이다. 그 이유만으로 다른 정당한 사유 없이 거절결정했다면 `0512`로 바꾼다. 해당 시점의 청구항 전체·종속항·명세서와 결정서를 대조한 후 판정한다. 예시는 자동 판정 규칙이 아니다.

### 내용의 오류와 표현의 오류

- 법조항 미기재·오기 또는 이유와 법조항의 불일치는 `1221`; 이유가 포괄적·모호하여 정당한 의견제출 기회를 제공하지 못하면 `1222`; 인용발명의 실체 불명은 `1223`; 첨부문헌 문제로 인용발명 특정이 **불가능**하면 `1224`, 특정은 **가능**하면 `1232`; 양발명의 대비 기재 미흡은 `1225`와 경미한 `1231`의 기준·영향을 원문 예시에 비추어 구별한다.
- `1231`은 문헌 조합·기술대비의 미흡, 과도한 축소 유도, 자의적인 진보성 논리 및 아래 적용 기준에 해당하는 오기 등 원문 ①–⑫의 **경미한 사항**을 포함한다. 이유 자체가 성립하지 않는 실체적 판단과 혼동하지 않는다.
- 거절결정서가 출원인의 핵심 주장·보정 검토를 누락하여 **최종결정에 명백하게 영향**을 주면 `1311`, 그 조건을 충족하지 않는 심사기준 불부합은 `1321`, 경미한 기재사항은 `1331`이다. 통지되지 않은 새 이유만으로 거절결정했는지 등 의견제출기회 문제는 `1011`도 확인한다.
- `1511`은 `1521`과 `1522`를 모두 만족하고 타 심사관의 모범인 사례다. `1521`은 적절한 선행기술 활용, `1522`는 논리적이고 간결한 심사통지서의 (1)–(4) 요건을 요구하며, 두 코드에는 원문 공통사항(일괄 통지·적절한 거절이유·검색이력·등록이유·바람직하지 않은 심사행위 부재)을 모두 확인한다.

### `1231`의 오기 적용 기준 — 통지서만으로 정정 가능한지

사용자 평가관이 2026-10-11에 확인한 운영 기준이다. 위 공식 진단유형의 문구를 변경하는 것이 아니라, 의견제출통지서의 오기에 대한 적용 범위를 구체화한다. 검사 절차는 OA-14를 따른다.

- **원칙적으로 제외:** 통지서 자체의 표·앞뒤 기재·기술적 문맥만으로 오기라는 사실과 올바른 의미를 명백하게 알 수 있는 단순오기는 `1231`을 부여하거나 진단 문제 건수에 포함하지 않는다. 필요하면 비집계 편집 메모로만 표시한다. 예: 표와 문맥이 `300 nm`임을 명백히 보여주는데 본문 한 곳이 `300 m`인 경우.
- **예외적으로 부여:** 통지서만으로는 단순오기를 확정·정정할 수 없고, 해당 구성의 존재 위치나 정확한 수치범위를 알기 위해 인용발명 원문을 읽어야 하며 실제 오기가 확인되면, 출원인의 추가 확인 부담을 발생시킨 경미한 기재 하자로 `1231`을 부여한다. 예: 구성의 식별번호 오기, 실제 `0.01~10 μm`인 범위를 `0.01~1.0 μm`로 옮긴 경우. 첨부된 인용문헌을 읽어야 하는 경우도 이 예외에 포함한다.
- **적용 범위:** 단위·숫자·식별번호라는 오류 유형만으로 자동 판정하지 않는다. 통지서만으로 올바른 내용을 명백히 복원할 수 있는지를 개별 확인한다. 두 수치범위가 겹치지 않는다는 내부 모순을 알아챌 수 있더라도, 어느 수치 또는 결론이 잘못됐는지 원문을 읽어야 알 수 있다면 단순오기로 제외하지 않는다. 나중 결정서에서 정정됐다는 이유로 최초 통지의 고객지향성 하자가 없어지는 것은 아니다.
- **증거와 코드 구별:** 인용발명 원문을 확보하지 못했다면 오기 의심·조건부 점검으로 남기고 `1231`을 확정하지 않는다. 법조항의 불일치, 거절이유 불명료, 대비의 실질적 부족, 실체 판단 오류는 해당 코드의 요건으로 별도 평가한다. 같은 오기를 다른 코드와 중복 집계하지 않고, 이 단순오기 제외 기준을 법조항 오류나 실체적 오류 전반으로 확대하지 않는다.


### 최초부터 존재한 이유를 최후로 통지한 경우 — `1024`와 `1031`

- 최후통지가 있으면 OA-15를 필수 적용한다. 보정 전부터 존재하며 보정으로 발생하지 않은 거절이유를 최후로 통지한 것이 확인되면 공식 유형 `1024`(최초거절이유와 최후거절이유의 혼동)를 적용한다. 새 문헌·새 법조항·나중 발견이라는 사실만으로 보정에 따른 발생을 인정하지 않는다.
- 최초부터 있던 이유를 일괄 통지하지 않고 나누어 통지한 문제는 `1031`의 정당한 사유 제외 조건을 따로 확인한다. 같은 사실에 두 코드를 자동 중복 집계하지 말고 별개 절차 하자인지와 선택 근거를 적는다.
- 보정으로 추가·삭제·변경된 구성과 해당 이유의 발생 사이에 실제 인과관계가 있는지 보정 전후 전체 청구범위로 판단한다. 필요한 판본·증거가 부족한 사항에 확정 코드를 붙이지 않는다.


### `바람직하게`·`특히`의 잔존 기재불비 — `0511`

- OA-17·RC-07에 따라 선호·강조 표현과 이중한정을 필수 점검한다. 청구범위에 남지 않도록 정리해야 할 중요 사항이며, 명확성·해석 하자가 남은 채 특허결정된 경우 공식 유형 `0511`로 표시한다. 발명의 설명에 사용된 표현을 같은 하자로 집계하지 않는다.
- 이중한정에 대한 정당한 명확성 통지에 `0521`을 붙이지 않는다. `임의로`·`선택적으로`의 명확한 선택적 구성과 혼동하지 않는다. 심사 중 해소된 경우 최종 잔존 하자 `0511`을 적용하지 않으며, 미지적 후 자연 해소 유형은 `0534`의 조건을 별도 확인한다.
