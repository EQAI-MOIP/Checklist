큐리 심사 체크 v1.0.0
작성일: 2026-11-23

이 앱은 사용자의 요청에 따라 두 저장소의 자료를 참조하여 작성한
오프라인 HTML/CSS/JavaScript 자기 점검 도구입니다.

참조 원문
- EQAI-MOIP/EQAI_sheet
  25fe5aaf25ad1dd6169cb4237723bb8c94b98e58
- EQAI-MOIP/AI_Reviewer
  4d078c8256953de164d8b13196502440c0fc30d0

기준의 원문 및 출처는 references/와 docs/RULES_AND_SOURCES.md에 있습니다.
체크 질문·설명은 자기 점검용으로 재구성했습니다. 공식 상세 매뉴얼의
전체 내용이나 최신 법령을 확보한 것으로 간주해서는 안 됩니다.
진단코드는 참고 후보이며 앱이 코드나 법적 결론을 자동 부여하지 않습니다.

큐리 WebP 자산은 위 AI_Reviewer 저장소에서 가져온 원본입니다.
자산 정보·해시는 assets/README.txt, 해당 저장소의 기존 고지는
assets/original-notice.txt에 보존했습니다. 기존 고지는 원본 앱에 대한
기록이며, 이 패키지에 API 호출·문서 판독 기능이 있다는 의미는 아닙니다.
기존 저작물의 권리를 확장하거나 별도의 공개 라이선스를 부여하지 않습니다.

앱 실행에 서버, Node.js, npm, 외부 패키지, CDN, API 키가 필요하지 않습니다.
tests/의 검증 코드는 개발용이며 Node.js의 기본 모듈만 사용합니다.
원문 문서, 사용자 API 키, 실제 업무 데이터는 이 ZIP에 포함하지 않았습니다.
연습용 심사건은 앱에서 명시적으로 만들 때만 생성되는 가상 데이터입니다.

브라우저 자동 저장과 JSON 백업 저장은 서로 다릅니다.
기록은 자동으로 앱 폴더에 저장되지 않으며, 백업은 사용자가 내려받아
보관해야 합니다. 실제 검증 범위는 docs/VALIDATION.md를 확인하세요.
