선택적 API 실행 도우미는 Node.js 기본 모듈을 사용합니다. Node.js 런타임은 포함하지 않습니다.

AI 품질진단 시스템 2026.11.12 / diagnostic / portable의 제공된 규칙 원문과 진단코드를 포함합니다.
APIKEY.md와 개인 API 키, 실제 업무 문서는 포함하지 않습니다.
앱의 사용자 호칭은 심사관님입니다. 캐릭터 큐리가 AI 심사팀장 역할로 진단과 근거를 안내합니다.

이 패키지는 기존 저작물의 권리를 확장하거나 별도의 공개 라이선스를 부여하지 않습니다.

프레임 위치와 사용 정보는 assets/quri-v2-sprites.json을 확인하세요.

내 문서로 진단은 출원번호와 KIPRIS Plus 키 없이 시작할 수 있습니다.
파일 추가와 로컬 예비 점검은 원문을 외부에 보내지 않습니다. AI 진단 실행 시 설정한 LLM으로 필요한 자료를 보냅니다.
로컬 예비 점검은 규칙 전체의 AI 검토가 아니며 확정 반려 판정을 자동 생성하지 않습니다.
판정에는 확보한 원문·적용 시점·진단규칙과 코드 조건의 확인이 필요합니다. 미확인 범위는 보류됩니다.
반려사항 발견 없음은 확인한 자료와 적용한 범위의 결과이며 무오류 보증이 아닙니다. 예시는 합성 자료입니다.

API 키·설정·사건은 자동 영구 저장되지 않습니다. 필요한 사건은 탭을 닫거나 새로고침하기 전에 다운로드하세요.
실제 개인 API 키와 실제 업무 문서를 이용한 운영 진단 성능 시험은 제작 검증에 포함되지 않습니다.
구현 및 화면 검증 범위와 확인하지 못한 사항은 docs/VALIDATION.md를 확인하세요.
